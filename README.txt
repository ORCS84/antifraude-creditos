# COMPILACION FACIL - 3 OPCIONES

OPCION 1 (MAS FACIL - SIN INSTALAR NADA):
1. Sube esta carpeta a un repo en GitHub
2. Ve a Actions -> espera 4 min
3. Descarga APK en Artifacts

OPCION 2 (LOCAL):
npm install
npx cap add android
npx cap copy
npx cap open android
Build > Build APK

OPCION 3 (PLAY STORE):
En Android Studio: Build > Generate Signed Bundle
